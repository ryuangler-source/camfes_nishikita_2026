# 西宮北口キャンフェス — SVG構成維持版

Desktopの14枚のSVGを各HTML内にインラインで配置しています。元の順序・配置・比率・色・文章を維持し、画面幅に合わせて全体を拡縮します。モバイルでも段組みの変更や並べ替えはしません。ブラウザのピンチズームを利用できます。

内部の制作コメント1箇所は来場者向け内容ではないため非表示にしています。企画カード、Googleマップ、トップへ戻るにリンクを設定しました。企画ページ末尾にはホームへのリンクがあります。

元のフォントファイルは提供されていないため、端末のフォントで代替される場合があります。元資料の時間の不一致は書き換えていません。

VS Codeでfestival-new.code-workspaceを開き、ターミナルで実行：

```sh
python3 -m http.server 8001 --bind 127.0.0.1
```

http://127.0.0.1:8001 を開きます。元のSVGと以前のcampus-festivalフォルダは変更していません。
